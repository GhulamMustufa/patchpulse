# PatchPulse — 2-Minute Demo Video Script

Follow this clear, plain-English walkthrough when recording the product demo.

---

### [ 0:00 – 0:20 ] The Problem & Opening
> **Audio:** "Older Python and JavaScript repositories often fail on modern systems—not because the logic is wrong, but because syntax rules and packages changed. Generic AI chat tools guess fixes without proving they run. That's why we built **PatchPulse**: it finds what broke, fixes it, and proves it with real offline tests."
> **Visual:** Show the `/` landing page, highlight the headline, and toggle the interactive **Python / JavaScript / TypeScript** preview card.

---

### [ 0:20 – 0:50 ] 1-Click Workspace & Code Fix
> **Audio:** "Anyone can test PatchPulse in one click—no login or API key needed. Let's open the workspace at `/lab`, pick the outdated Python project, and click **Fix Code**."
> **Visual:** Click **Open Live Workspace**, click **Fix Code**, show the **Original Code** vs. **Fixed Code** diff side-by-side and the **Issues** tab.

---

### [ 0:50 – 1:25 ] Honest Telemetry & Isolated Test Execution
> **Audio:** "Notice PatchPulse doesn't mark the project healthy right away—it stays at *Syntax OK • Tests Not Run* until real tests actually pass. Once I review the diff, click **Approve Fix**, and click **Run Tests**, PatchPulse runs the tests inside an offline sandbox with zero internet or host access."
> **Visual:** Click **Approve Fix**, click **Run Tests**, open the **Test Results** and **Logs** tabs to show real test output and the live health monitor turning green.

---

### [ 1:25 – 1:45 ] Multi-Language & GitHub Repo Support
> **Audio:** "PatchPulse supports Python 3.12, JavaScript on Node 20, and TypeScript 5.9—including real `tsc --noEmit` checks. You can also load any public GitHub repository or `.zip` archive right from the **GitHub or ZIP** tab, and check system readiness at `/dashboard`."
> **Visual:** Briefly switch to **GitHub or ZIP** tab, then flash `/dashboard` and `/docs`.

---

### [ 1:45 – 2:00 ] Closing
> **Audio:** "Every line of PatchPulse is backed by 40 automated security and verification tests. Check out the repo at `github.com/GhulamMustufa/patchpulse` and try it yourself."
> **Visual:** Return to `/` landing page with the PatchPulse logo and GitHub link.
